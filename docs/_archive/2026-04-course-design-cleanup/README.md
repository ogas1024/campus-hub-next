# 2026-04 课程设计聚焦调整归档

本批次归档产生于 2026-04 的目录整理。

## 归档原因

- 当前课程设计虽然题目保持为“校园生活平台”，但本轮只聚焦：
  - 平台基础：身份与鉴权、组织结构、RBAC、数据范围、审计日志
  - 核心业务：功能房预约、课程资源分享
  - 可选扩展：数字图书馆
- 因此将暂不纳入本轮主线的历史文档移出当前入口，但保留在归档目录中。

## 归档内容

- `root/`：顶层历史协作/阶段性说明文档
- `api/`：已退出当前主线的历史 API 文档
- `requirements/`：已退出当前主线的历史需求文档
- `report/`：已退出当前主线的历史报告文档

## 使用说明

- 如需回溯历史设计，可以直接从本目录查看。
- 如某模块后续重新进入主线，应从归档中挑选可复用内容，再整理回正式目录，而不是直接继续引用归档版本。
