# Submission PDF

本目录用于存放“校园生活平台需求分析报告”的 PDF 提交材料。

目录说明：

- `校园生活平台需求分析报告.md`
  - PDF 导出源文件
- `build.sh`
  - 构建脚本
- `assets/mermaid/`
  - Mermaid 图源文件
- `assets/rendered/`
  - 构建过程中生成的 PNG 图像
- `校园生活平台需求分析报告.pdf`
  - 最终导出的 PDF

说明：

- 本目录与 `../13-需求分析小节简版.md` 保持同一份需求分析口径。
- 构建脚本会通过 `kroki.io` 将 Mermaid 图渲染为静态图片，因此需要可用网络。
