# Requirements Analysis AGENTS

## Purpose

- This directory stores the formal requirements analysis deliverables for the current database course design phase.
- It is report-oriented and defense-oriented.

## Scope

- Topic remains: "校园生活平台"
- Current primary scope:
  - platform core
  - facility reservation
  - course resources
  - optional library extension

## Writing rules

- Prefer Chinese.
- Prefer formal course-report style over lightweight engineering notes.
- Keep documents usable both as:
  - report source material
  - standalone orientation material in a new conversation

## Content rules

- Requirements analysis should stay at the level of:
  - background
  - goals
  - feasibility
  - scope
  - actors
  - business process
  - functional requirements
  - data requirements
  - non-functional requirements
  - scheme comparison
- Avoid mixing detailed schema design into this directory unless used only as a requirement-level preview.

## Sync rules

- If current scope changes, update `README.md` and `10-正式需求分析稿.md` first.
- If a new report-ready conclusion is formed, make sure the polished version stays in sync with the supporting analysis files.
