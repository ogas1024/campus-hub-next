# 需求分析文档目录

本目录用于存放《数据库原理及应用》课程设计题目“校园生活平台”的正式需求分析材料。该目录的定位不是零散笔记，而是课程设计报告“需求分析”章节的主来源，也是后续概念结构设计、逻辑结构设计、物理结构设计与测试设计的前置依据。

## 使用定位

- 面向课程设计报告撰写：
  - 可直接从本目录提炼正式报告正文
- 面向后续数据库设计：
  - 为 E-R 图、关系模式、主键外键、完整性约束提供依据
- 面向答辩准备：
  - 用于说明“为什么选择这些模块”“为什么这样建模”“为什么采用这些约束”

## 当前课题主线

- 平台基础子系统：
  - 身份与鉴权
  - 组织结构
  - RBAC
  - 数据范围
  - 审计日志
- 核心业务子系统：
  - 功能房预约
  - 课程资源分享
- 可选扩展：
  - 数字图书馆

## 文档结构

- `00-编写说明与术语约定.md`
  - 定义术语、缩略语、需求编号规则和本目录使用边界
- `01-课题背景与建设目标.md`
  - 说明课题来源、现实背景、建设意义和总体目标
- `02-可行性分析.md`
  - 分析技术、经济、操作、进度和组织可行性
- `03-系统范围与边界.md`
  - 明确纳入范围、排除范围、外部边界、约束条件和前提假设
- `04-用户角色与业务场景.md`
  - 定义系统参与者、职责、业务目标和典型业务场景
- `05-业务流程分析.md`
  - 梳理核心业务流程、备选流程、异常流程及其数据库含义
- `06-功能需求规格.md`
  - 形成标准化功能需求清单与编号体系
- `07-数据需求分析.md`
  - 识别主要业务对象、联系、完整性需求和后续数据库设计关注点
- `08-非功能需求.md`
  - 明确性能、安全、一致性、可靠性、可维护性、可测试性等要求
- `09-方案比较与选型依据.md`
  - 对范围、运行环境、认证、外键、约束和建模方案进行比较分析
- `10-正式需求分析稿.md`
  - 当前课堂分享与提交优先使用的正式版需求分析报告
- `12-课堂分享版需求分析报告.md`
  - 更基础、更收敛的课堂提交版需求分析报告
- `13-需求分析小节简版.md`
  - 仅保留“2.3 需求分析”这一小节的简版内容
- `submission-pdf/`
  - 单独存放 PDF 提交版源文件、构建脚本、图源与导出结果
- `11-需求到数据库设计跟踪矩阵.md`
  - 将需求与后续 E-R 图、关系模式、约束、索引和测试重点建立对应关系

## 与仓库其他文档的关系

- 本目录是“正式需求分析材料”的主入口
- `docs/course-design/` 用于沉淀课设口径、答辩策略和总体指导
- `docs/requirements/` 保留模块级工程需求文档，可作为本目录的补充业务来源
- `docs/report/` 是后续正式报告分模块写作的承接目录

## 当前建议的工作顺序

1. 先冻结需求分析口径
2. 再做概念结构设计与 E-R 图
3. 再做关系模式设计与规范化说明
4. 再做物理设计、SQL、约束与测试

这一路线更符合数据库课程设计的标准过程，也更利于答辩时按照“需求分析 -> 数据建模 -> 约束设计 -> 实现验证”的逻辑展开。
